**Dashboard－風險預警頁企劃簡版**：

第一排做 **5 個 KPI**：

1. 高風險商機數：目前被判定為高風險的商機總數
2. 逾期未跟進案件數：超過預定跟進時間仍未處理的案件數
3. 即將失效商機數：預計成交日將近但仍未推進的案件數
4. 客訴 / Issue 未結案數：目前尚未完成處理的客訴或 Issue 數
5. 預測落差案件數：Forecast 與實際落差過大的案件數

第二排做 **風險分布區**：

1. 風險類型分布圖：使用 **Donut Chart**，顯示各類型風險占比，例如逾期未跟進、商機停滯、客訴 / Issue、預測異常
2. 風險等級分布圖：使用 **橫向條狀圖**，顯示高 / 中 / 低風險案件數
3. 負責人風險比較圖：使用 **堆疊柱狀圖**，依高 / 中 / 低風險分層比較各夥伴目前名下風險案件數

第三排做 **診斷分析區**：

1. 商機停滯階段分析圖：不用漏斗圖，改用 **橫向條狀圖** 或 **Heatmap**，顯示案件主要卡在哪些階段，例如初步接觸、需求確認、報價、議價
2. 逾期天數分布圖：使用 **Bar Chart**，顯示 1–3 天、4–7 天、8 天以上的案件數量分布
3. 客訴 / Issue 趨勢圖：使用 **Area Chart**，顯示近一段時間的新增客訴或待處理 Issue 變化趨勢

第四排做 **待處理風險清單**：
使用 **Table** 呈現，內容包含：

1. 案件名稱
2. 客戶名稱
3. 負責人
4. 風險類型
5. 風險等級
6. 停滯 / 逾期天數
7. 最後跟進時間
8. 查看詳情 / 處理按鈕

表格可搭配：

* Tag 顯示 danger / warning / info 狀態
* 支援依風險類型、風險等級快速篩選
* 點擊案件可進詳情頁或開 drawer 查看內容

整頁補充規劃：

* 頁面上方提供時間篩選，至少支援本月 / 本季 / 本年
* 所有區塊以 Card 包裝
* 圖表 loading 時顯示 Skeleton
* 第二排與第三排圖表需支援 tooltip 顯示詳細數值
