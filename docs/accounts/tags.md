# 客戶標籤頁企劃

## 一、頁面定位

客戶標籤頁不是單純「顯示 tag 清單」的設定頁，也不是客戶列表頁的另一個複製版本。
它的定位應該是：

**以 Account 為中心的「客戶標籤管理與分群頁」**

也就是說，這頁要解決的不是：

* 這家公司是誰
* 這家公司有哪些聯絡人

而是：

* 我有哪些客戶被標記為某類型
* 哪些客戶同時具有多個標籤
* 哪些標籤最常被使用
* 我如何快速用標籤做分群與管理
* 我如何批次補標籤或移除標籤

這和你企劃中的客戶管理設計是對齊的，因為你已經把 Account 定義為主體，並在功能架構中明確提到客戶標籤與分類；目前 mock data 也已經在 account 資料中放入 `tags` 陣列。

---

## 二、這頁和其他頁面的差異

### 1. 與客戶列表頁的差異

* 客戶列表頁：重搜尋、找客戶、進詳情
* 客戶標籤頁：重分群、看標籤、用標籤管理客戶

### 2. 與客戶分級頁的差異

* 客戶分級頁：以 `tier` 為固定分類維度
* 客戶標籤頁：以 `tags` 為彈性分類維度

### 3. 與設定頁標籤管理的差異

若未來有獨立「標籤設定」頁，則：

* 設定頁：管理標籤字典、名稱、顏色、啟用狀態
* 客戶標籤頁：用標籤管理實際客戶

所以這頁本質比較像：

```text id="2qf7m6"
Customer Tag Workspace
```

而不是純設定頁。

---

## 三、頁面目標

這頁要達成的任務：

* 查看所有已存在的客戶標籤
* 快速知道每個標籤下有哪些客戶
* 依標籤切換客戶清單
* 找出高頻使用標籤
* 對客戶新增 / 移除標籤
* 支援批次加標籤 / 批次移除標籤
* 作為 BD / Manager 的分群管理頁

## 六、資料基礎

你目前 `accounts.js` 已經有：

* `id`
* `companyName`
* `accountCode`
* `companyType`
* `tier`
* `lifecycleStage`
* `region`
* `owner`
* `status`
* `updatedAt`
* `tags[]` 

所以第一版這頁**可以直接以 Account 為資料源成立**，不一定要先抽獨立 `tags.js`。

但從長期架構來看，建議採兩層設計：

### 第一版

* `accounts.js` 內 `tags[]` 作為標籤來源

### 第二版

* 可抽出 `tagOptions.js` 或 `tags.js`
* 作為標籤字典來源

## 八、頂部摘要卡企劃

這頁和客戶分級頁一樣，建議要有摘要卡，否則和一般列表頁太像。

### 1. 總客戶數

* 所有 Account 數量

### 2. 標籤總數

* 去重後的 tag 數量

### 3. 已標籤客戶數

* `tags.length > 0` 的客戶數

### 4. 未標籤客戶數

* `tags.length === 0` 的客戶數

這些卡片不需要圖表，數字即可。

## 九、熱門標籤區企劃

這頁最重要的特色不是表格，而是 **Tag Wall / 熱門標籤區**。

## 9.1 呈現方式

* 一組可點擊的 `ElTag` / Pills
* 顯示：

  * 標籤名稱
  * 使用次數

例如：

```text id="298u2f"
[聯名活動 12]
[數位通路 9]
[高潛力 7]
[東南亞 6]
[媒體曝光 4]
```

## 9.2 行為

* 點擊某標籤 → 篩選列表
* 再次點擊可取消
* 支援單選或多選（第一版建議先單選）

## 9.3 作用

* 讓這頁和客戶列表真正有區隔
* 使用者先從群組看，再往下看客戶清單

## 十三、是否允許建立新標籤

這是一個產品決策點。

## 13.1 第一版建議

**允許建立新標籤，但要很克制。**

原因：

* 你的 mock data 已經顯示 tag 是高彈性的
* 若完全不能新增，使用者會被綁死
* 但若毫無規範，標籤很容易失控

## 13.2 建議規則

第一版可採：

* 在編輯標籤時可新增新 tag
* tag 名稱不可重複（忽略大小寫 / 空白）
* 不提供獨立「標籤設定中心」

第二版再考慮：

* 標籤字典管理
* 標籤顏色 / 類型 / 狀態
* 禁用舊標籤

## 十四、頁面關鍵價值：分群視角

這頁要和客戶列表真正拉開差距，關鍵在於：

**讓使用者從「標籤」視角看客戶，而不是從「客戶」視角看標籤。**

所以你在 UI 上應該讓人先看到：

* 哪些 tag 最常用
* 點某個 tag 就切出對應客戶清單

而不是只在表格裡有一欄 tags。

## 十九、最終決策

* 客戶標籤頁要做
* 它不是客戶列表的複製頁，而是 tag 分群管理頁
* 第一版可直接使用 Account.tags 成立
* 此頁一定要有：

  * 標籤摘要
  * 熱門標籤區
  * 標籤編輯操作
* 單筆 / 批次編輯標籤用 Dialog，不開新頁
* 點客戶名稱進 Account Detail Tab
