# 報表中心｜客戶分析頁企劃

## 一、頁面定位
客戶分析頁是報表中心中「管理決策導向」的核心頁面，目的不是維護客戶資料，而是回答：
- 客戶結構是否健康
- 哪些客戶最有價值
- 哪些客戶正在流失或高風險
- 團隊經營是否有效

本頁定位為「分析頁」，而非「管理頁」；主行為是觀察、比較、下鑽，並跳轉到客戶詳情完成後續處理。

## 二、頁面目標
1. 提供管理層可快速解讀的客戶經營 KPI。
2. 呈現客戶結構、價值、活躍度與流失風險。
3. 支援從圖表下鑽到明細清單，再跳轉客戶詳情。
4. 統一與其他報表頁（商機分析、營收分析）的互動樣式。

## 三、適用角色
- 管理者（Manager / Executive）：全域檢視、策略決策。
- 營運與分析角色（Ops / Analyst）：追蹤分群與趨勢。
- 業務主管：比對 owner / 團隊經營成效。
- 一般業務：僅看自己權限範圍（可選）。

## 四、頁面結構
採「分析主導、清單輔助」：
1. 頂部 KPI 摘要卡
2. 查詢 / 篩選區
3. 主分析圖表區（多區塊）
4. 下方客戶明細區（可切換名單）

## 五、核心 KPI（頂部摘要卡）
建議第一版 8 張卡：
1. 客戶總數
2. 本期新增客戶數
3. 活躍客戶數
4. 流失客戶數
5. 客戶流失率
6. 平均客戶價值
7. 高價值客戶數
8. 有商機客戶占比

每張卡建議顯示：
- 當前值
- 與上期比較（差值 + 百分比）
- 趨勢箭頭（上升 / 下降）

## 六、KPI 定義（計算口徑）
- 客戶總數：有效客戶（排除刪除/封存）
- 本期新增客戶數：建立時間落在篩選期間
- 活躍客戶數：近 N 天內有互動 / 商機 / 合約 / 營收任一事件
- 流失客戶數：lifecycle = churn 或符合流失規則
- 流失率：流失客戶數 / 期初客戶數
- 平均客戶價值：客戶累積營收 / 客戶數（或 LTV 均值）
- 高價值客戶數：客戶價值 >= 門檻（例如 P80）
- 有商機客戶占比：有商機客戶數 / 客戶總數

備註：所有比例計算需固定小數位（建議 1 位）並標示分母定義，避免誤解。

## 七、篩選條件
第一版建議：
- 日期區間（預設近 90 天）
- 客戶類型（partner / distributor / channel / enterprise）
- lifecycle stage（lead / deal / retention / churn）
- 客戶分級（strategic / normal / potential）
- 地區
- 產業
- owner / 部門
- 是否有商機
- 是否有合約
- 是否有營收
- 是否高風險 / 流失
- 關鍵字（客戶名稱、編號）

## 八、主分析圖表（MVP）

### A. 客戶結構
1. 客戶類型分布（Donut）
2. 客戶地區分布（橫向長條）
3. 客戶分級分布（Donut 或直條）
4. lifecycle stage 分布（漏斗或堆疊長條）

### B. 客戶價值
1. 客戶價值分布（直條：高/中/低）
2. Top 客戶營收貢獻排行（橫向長條）
3. 平均客戶價值趨勢（折線）

### C. 客戶活躍與經營
1. 客戶活躍度分布（高 / 中 / 低 / 無互動）
2. 最近互動趨勢（折線）
3. 有商機 / 無商機占比（Donut）
4. 有合約 / 無合約占比（Donut）

### D. 流失與風險
1. 流失率趨勢（折線）
2. churn 客戶數趨勢（直條）
3. 流失原因分類（橫向長條）
4. 高風險客戶數（KPI 或小趨勢圖）

## 九、下方明細區
提供「分析後行動」入口，建議用 Tab 切換名單：
- 高價值客戶
- 成長客戶
- 低活躍客戶
- 流失客戶
- 高風險客戶

欄位建議：
- 客戶名稱
- 客戶類型
- 地區
- owner
- lifecycle stage
- 客戶分級
- 最近互動時間
- 最近商機時間
- 客戶價值 / 累積營收
- 風險狀態

每列可直接跳轉客戶詳情頁。

## 十、互動邏輯
1. 點圖下鑽：點圖表 segment 後，明細區自動套用對應篩選。
2. KPI 聯動：點 KPI 可切換到對應圖表區塊與名單 Tab。
3. 篩選同步：篩選條件同時作用於 KPI、圖表與表格。
4. 狀態保留：返回頁面時保留上次篩選與 Tab（可選）。

## 十一、與其他頁面的分工
- 客戶管理頁：資料維護與單客戶操作
- 客戶詳情頁：單客戶完整追蹤與處理
- 客戶分析頁：跨客戶決策分析與風險辨識

本頁不提供大量資料編輯，避免與管理頁重疊。

## 十二、資料來源與欄位對應
主要來源（可由前端 mock，後端再接）：
- Account：基本資料、類型、分級、lifecycle、owner、地區、產業
- Opportunity：是否有商機、最新商機時間、商機金額
- Contract：是否有合約、合約狀態
- Revenue：客戶營收、累積價值
- Interaction/Timeline：活躍度與互動趨勢

## 十三、權限與可見性
- Admin / Manager：可看全域
- Team Lead：可看所屬團隊
- Sales：可看本人 owner 範圍

所有 KPI 與比例需基於可見資料重新計算。

## 十四、MVP 範圍
### 納入
- 8 張 KPI 卡
- 基本篩選
- 4 大分析區塊（至少 10 張關鍵圖）
- 明細區 + 客戶詳情跳轉
- 點圖下鑽

### 不納入
- 複雜預測模型（如 ML churn 預測）
- 自訂報表設計器
- 報表內直接批次編輯客戶

## 十五、驗收標準
1. 篩選後 KPI、圖表、明細數字一致。
2. 點任一圖表區塊可下鑽到正確客戶名單。
3. 高風險/流失客戶可一鍵跳客戶詳情。
4. 管理者視角與業務視角數據範圍正確。
5. 頁面在常見資料量下可順暢操作（無明顯卡頓）。

## 十六、後續擴充方向
1. 新增客戶健康分數（Health Score）。
2. 新增 cohort 留存分析。
3. 加入預警訂閱（每日/每週寄送高風險客戶名單）。
4. 與任務系統連動（對高風險客戶自動建立追蹤任務）。
