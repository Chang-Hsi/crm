**Dashboard－夥伴績效頁企劃簡版**：

第一排做 **5 個 KPI**：

1. 成交金額：顯示本月累計成交金額
2. 成交單數：顯示本月成功成交案件數
3. 達成率：顯示個人或團隊實績 / 目標百分比
4. 平均客單價：顯示平均每筆成交金額
5. 毛利 / 預估毛利：若有報價或訂單資料則顯示，沒有可先不做

第二排做 **夥伴排名與比較區**：

1. 夥伴業績排行橫向條圖：顯示各夥伴成交金額排名，並加上平均值參考線
2. 商機轉換率比較圖：顯示各夥伴從新建、洽談、報價到成交的轉換表現，圖表建議用堆疊柱狀圖，並可切換本月 / 本季

第三排做 **診斷分析區**：

1. 夥伴商機階段分布圖：不用漏斗圖，改用 **100% 堆疊柱狀圖**，顯示每位夥伴案件目前分布在哪些階段，例如新建、洽談、報價、議價、成交、流失
2. 跟進次數 vs 成交金額散點圖：用來觀察夥伴的投入與產出關係，幫助判斷哪些人高頻高效、哪些人高頻低效
3. Forecast vs Actual 圖：顯示預測業績與實際業績差異，幫助主管快速看出落差

第四排做 **待關注名單區**：
用 Table 呈現，不用圖表，內容包含：

1. 達成率偏低夥伴
2. 商機卡關夥伴
3. 客訴 / Issue 偏高夥伴
4. 逾期未跟進案件負責人

表格內可搭配：

* 狀態 Tag 顯示風險等級
* Progress 顯示達成率
* 點擊夥伴或案件後可進詳情頁或展開 drawer 查看內容

整頁補充規劃：

* 頁面上方提供時間篩選，至少支援本月 / 本季 / 本年
* 所有區塊以 Card 包裝
* 圖表 loading 時顯示 Skeleton
* 第二排與第三排圖表都要支援 tooltip 顯示明細數值
